# Otome FavList 日乙喜好生成表
乙女游戏角色/CP喜好清单生成工具，GitHub Pages直接部署使用

## 目录说明
- index.html：页面入口
- css/main.css：全局样式
- js/main.js：交互、导出、本地存储、渲染逻辑
- js/loader.js：自动加载所有游戏数据
- data/games.js：游戏数据聚合入口
- data/games/：每个乙女游戏独立数据文件（新增游戏只改这里）
- img/game/：游戏封面图
- img/char/：角色200×200px头像缩略图

## 部署方法
1. 仓库命名：用户名.github.io
2. Settings → Pages → 分支main，根目录/，保存
3. 等待2分钟，访问 https://用户名.github.io

## 新增游戏操作（仅2步，不修改核心代码）
### 步骤1：新建游戏数据文件
1. 进入 data/games/ 文件夹
2. 复制模板文件 game001.js，重命名为 gameXXX.js（编号自增，唯一ID）
3. 修改文件内游戏基础信息、角色数据
   - isHidden=true：隐藏角色，需开启开关显示（剧透）
   - isFD=true：续作/FD限定角色
   - imgs数组填写该角色所有头像图片文件名

### 步骤2：上传图片
1. 游戏封面 → img/game/
2. 角色头像(200*200正方形) → img/char/

### 生效
提交文件后刷新页面，添加游戏列表自动加载新游戏，支持搜索、筛选、角色/CP选择

## 功能说明
1. 全局开关：全局隐藏角色、全局FD角色，切换必弹出剧透警告
2. 单游戏独立开关，首次开启弹窗确认，浏览器本地记住不再重复提示
3. 基础资料填写：昵称、游玩数、入坑时间、入坑作品，空白导出自动忽略
4. 游戏筛选：名称搜索、发售年份、发行商、汉化组、编剧、原画多维度筛选
5. 喜爱度：五颗爱心主观打分
6. Character角色：女角色A-Z排序→男角色A-Z排序，头像多图切换，自动换行
7. Couple布局：固定左25%女主区域（居中），右75%男主流式自动换行，多CP分行展示
8. 图片导出：锁定小杉圆体粗体，自定义纯色背景/标题/正文/卡片边框，多尺寸支持
   尺寸：810×1080 / 1080×1440 / 超长无分页 / 小红书1080×1920 / 微博1080×1080
9. 本地存储：所有填写、选择、配色永久保存在浏览器，刷新不丢失
