# Otome FavList

> 日乙个人喜好表生成工具 — 选择你喜欢的角色，生成属于你的 FavList。

这是一个纯前端、无需安装的 Web 应用，专为日乙玩家设计。你可以自由添加已玩过的游戏、选择喜欢的角色（支持单角色、多角色与 CP 组合）、用爱心评分，并一键导出为高清图片，用于分享或收藏。

---

## ✨ 功能特色

- **游戏库管理**：内置 90+ 款日乙游戏（持续更新），支持按编剧、画师、发行年份、厂商等筛选。
- **剧透保护**：全局/单游戏控制隐藏角色、续作/FD角色的显示，开启前会弹出剧透警告。
- **评分系统**：每款游戏可给予 1~5 颗爱心评分。
- **角色选择**：
  - **Character 模式**：为游戏卡片添加你喜欢的角色（支持多立绘切换）。
  - **Couple 模式**：为女主角搭配男主角，组成 CP 。
- **自定义文本**：每个游戏卡片可添加三段自由文本（分别位于游戏标题、Character 区域、Couple 区域下方），用于记录个人感想。
- **高度自定义导出**：
  - 多种尺寸：固定比例（如 640×853、810×1080）或长图模式（640/810/1080 宽）。
  - 自由配色：背景色、标题色、正文色、边框色等均可调整，且在网页中即时生效。
  - 导出折叠内容（开关控制是否包含折叠的游戏卡片）。
  - 隐藏角色名称的单独开关（适合仅展示剪影，防止剧透）。
- **预览及分页导出**：生成图片前先预览，多页内容自动分页并支持批量下载。
- **本地数据持久化**：所有配置（游戏列表、角色选择、自定义文本等）自动保存到浏览器本地，刷新页面不丢失。

## 🚀 如何使用

### 1. 访问地址
项目已部署至：  
otomefavlist.pages.dev

### 2. 添加游戏
- 点击「+ 添加游戏」打开搜索面板。
- 可按名称搜索，或使用编剧/画师/年份/厂商等筛选。
- 点击任意游戏卡片即可添加至列表。

### 3. 评分
游戏名称右侧有五颗爱心，点击即可为该游戏评分（1~5 颗爱心）。

### 4. 选择角色
每个已添加的游戏卡片下方有两个按钮：
- **选择角色 Character**：勾选你喜欢的角色（可多选，按照选择的顺序进行添加），点击确认保存。
- **选择角色 Couple**：点击女主卡片展开男主列表，勾选你心仪的 CP 组合，确认后保存。

> 💡 角色立绘支持多张图片切换（例如动作、服装差分或FD ver），点击左右箭头即可。

### 5. 添加自定义文本
在每个游戏卡片中各有三个文本框分别位于游戏标题、Character 区域、Couple 区域下方：
- **游戏标题下方文本框**：适合填写对整部游戏的短评或印象。
- **Character 区域下方文本框**：可针对所选角色添加感想等内容。
- **Couple 区域下方文本框**：可针对所选 CP 组合添加感想等内容。

> 💡 文本内容支持换行且会自动保存。

### 6. 自定义导出设置
- **导出折叠内容**：开启后，即使游戏卡片处于折叠状态，也会在生成的图片中完整显示。
- **导出隐藏/续作/FD 角色名**：关闭后，角色名不会出现在图片中（仅显示相应角色图片），适合搭配剪影图使用。
- **配色**：通过颜色选择器自由调整图片的配色方案，点击「恢复默认设置」可一键重置。
- **尺寸**：支持多种固定尺寸及长图模式，满足不同社交平台需求。

### 7. 生成并导出图片
点击「生成并导出图片」→ 预览弹窗出现 → 确认无误后点击「导出图片」即可下载（多页时自动分批下载）。

## 🛠 技术栈

- 原生 HTML5 / CSS3 / JavaScript（ES Module）
- Canvas 2D 绘制（导出图片，无第三方库依赖）
- localStorage 实现数据持久化
- 动态模块导入（`import()`）优化加载性能
- 响应式设计，适配 PC 与移动端

## 🔧 自定义与扩展

- **添加新游戏**：在 `data/games.js` 中按已有格式添加游戏对象，并在 `main.js` 的 `gameIdList` 数组中追加对应 ID。
- **自定义文本功能**：文本框在页面中直接可见，无需额外配置；如需在导出中调整样式，可修改 CSS 中 `.game-custom-text-wrap` 相关规则。
- **修改主题色**：直接在页面上使用颜色选择器调整，无需改代码。
- **调整导出尺寸**：在 `index.html` 的导出尺寸区域增加或修改 radio 选项即可。

## ❓ 常见问题

**Q：首次加载为什么较慢？**  
A：首次访问会加载 90+ 款游戏的图片资源（已达二千多张），请耐心等待加载完成。后续访问会利用浏览器缓存加速。

**Q：预览始终在加载状态？**  
A：首次加载需渲染大量图片；若非首次使用，通常是更新后旧缓存与新数据冲突导致加载阻塞，请清除缓存后重试。

**Q：导出的图片模糊或缺少角色？**  
A：请确保在导出前所有角色图片已完整显示。若仍有问题，可尝试刷新、更换浏览器或清除缓存重试。

**Q：数据会丢失吗？**  
A：所有数据保存在浏览器 localStorage 中，清除浏览器缓存或使用无痕模式会导致数据丢失。建议定期导出图片。
